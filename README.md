# Algoritmos de Búsqueda en Inteligencia Artificial

## Descripción del proyecto

Repositorio académico dedicado al estudio e implementación de algoritmos de búsqueda utilizados en Inteligencia Artificial para explorar espacios de estados y encontrar soluciones a problemas computacionales.

El proyecto aborda conceptos fundamentales de representación de problemas, exploración de alternativas y evaluación de soluciones mediante estrategias de búsqueda.

## Objetivos

- Comprender cómo se representa un problema mediante estados y acciones.
- Estudiar el concepto de espacio de búsqueda.
- Implementar estrategias de búsqueda en Python.
- Analizar la exploración de posibles soluciones.
- Comprender las diferencias entre las estrategias implementadas.
- Fortalecer los fundamentos de resolución algorítmica de problemas.
